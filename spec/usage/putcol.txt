USAGE : putcol columnfile intofile outfile colno -r|-i [[-]skiplines] [-e]

COLUMNFILE  File with NEW column.
INTOFILE    File INTO which the new column goes.
OUTFILE     Resultant file.
COLNO       POSITION of the column to be added.
-r          REPLACE original column.
-i          INSERT new column amongst original columns.
SKIPLINES   SKIP OVER skiplines before inserting column.
-SKIPLINES  THROW AWAY skiplines: then insert column.
-e          Ignore lines which contain only 'e' or 's'.
            and comment lines starting with ';'
            (skipped lines should still be counted).
