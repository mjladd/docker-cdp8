USAGE: pulser pulser 1 infile outfile dur pitch
OR:    pulser pulser 2 infile outfile dur
OR:    pulser pulser 3 infile outfile spacedata dur
minrise maxrise minsus maxsus mindecay maxdecay speed scatter
[-eexpr] [-Eexpd] [-ppscat] [-aascat] [-ooctav] [-bbend] [-sseed] (-wwidth])
ITERATE AN INPUT AND ENVELOPE THE SOUND GENERATED
TO PRODUCE PITCHED PACKETS WHICH ARE OUTPUT IN A STREAM.
MODE 1 : packets take spectral brightness (only) from source,
         and pitch from pitch parameter.
MODE 2 : packets derived from (start of) source.
MODE 3 : packets derived from random startpoints within source.
DUR          Duration of output stream.
SPACEDATA    Zero (stereo output) ~~OR~~ gives 8-chan output, and expects...
             String listing chans to use (vals from 1-8: in order, no repeats).
             OR datafile (8-channel output).
             Datafile consists of set of lines, each having
             Time & List_of_chans_to_use (vals in range 1-8: no repeated vals).
PITCH        (Mode 1) Midipitch of packets, Range 24 to 96 (may vary over time).
MIN,MAXRISE  Min and max risetime of packet envelope (Range 0.002 to 0.2 secs).
             (Risetime set as random value between the 2 limits)
MIN,MAXSUS   Min and max sustain of packet envelope (Range 0.0 to 0.2 secs).
             (Sustain set as random value between the 2 limits)
MIN,MAXDECAY Min and max decaytime of packet envelope (Range 0.02 to 2 secs).
             (Decaytime set as random value between the 2 limits)
SPEED        (Average) time between packets in output (Range 0.05 to 1sec).
SCATTER      Randomisation of speed (0-1)
EXPR         Rise slope (1 linear: >1 steeper: <1 shallower) (Range .25 to 4)
EXPD         Decay slope (1 linear: >1 steeper: <1 shallower) (Range .25 to 4)
PSCAT        Random jitter of pitch of packets: Range 0 - 1 semitones.
ASCAT        Random jitter of amplitude of packets: Range 0 (no jitter) to 1.
OCTAV        Amount of lower octave reinforcement : Range 0 - 1
BEND         Amount of upward pitchbend of packets : Range 0 - 1 semitones.
SEED         Same seed-number produces identical output on rerun (Integer >=1).
WIDTH        Mode 3 only :Range 0-1
             In Stereo ("SPACEDATA" = 0)
             Width of scatter-of-positions of packets, across stereo panorama.
                  Zero value produces Mono output.
             8-chan ("SPACEDATA" is a file of 8-chan spatialisatio data)
             Width of scatter-of-positions away from loudspeaker-centric.
                  Zero value produces outputs centred in the loudspeakers.
All params except DUR,SEED and MIN/MAX RISE,SUSTAIN,and DECAY can vary over time.
