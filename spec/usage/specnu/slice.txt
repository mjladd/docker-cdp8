USAGE:
specnu slice 1-3 inanalfile outanalfiles bandcnt chanwidth
specnu slice 4 inanalfile outanalfiles pitchdata
specnu slice 5 inanalfile outanalfile invertaroundfrq

Slices spectrum (frqwise) into mutually exclusive parts, or inverts
MODE 1: (moiree slice) -- chanwidth in analysis channels
puts alternate (groups of) channels into different slices: e.g.
bandcnt 3 chanwidth 1 -> outfil1: 0 3 6... outfil2: 1 4 7... outfil3: 2 5 8 ... 
bandcnt 2 chanwidth 2 -> outfil1: 0-1 4-5 9-8... outfil2: 2-3 6-7 10-11...
(bandcnt must be > 1)
MODE 2: (frq band slice) -- chanwidth in Hz
puts alternate (groups of) chans into different equal-width frq bands: e.g.
(bandcnt can be 1)
MODE 3: (pitch band slice) -- chanwidth in semitones
puts alternate (groups of) chans into different equal-width pitch bands: e.g.
(bandcnt can be 1)
MODE 4: (slice by harmonics) -- requires a text datafile of time-frq values
(generated by "repitch getpitch"). Outputs a file for each harmonic tracked.

With outfile "myname", produces files "myname", "mynam1", "myname2" etc.

MODE 5: (invert freqwise) -- requires frq value to invert around
