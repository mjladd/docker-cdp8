NB: The command line usage and Reference Documentation refers to 'packing' as the "(average) time between motif onsets" -- i.e., the time gap between the start times of iterations of the motif.

On the Sound Loom parameters page this is called "skiptime between motif onsets".  This (confusingly) is not the same as 'skiptime' in other texture programs, which is the time between time-templates, beginning on the last note-event of the template.

'Packing' is the correct term as it deals with note event onset times.

These batch files are shown mainly so that there is a reference to the 
list of parameters in TEXTURE MOTIFS.  They also show how CDP can be run from the command line.

NOTES (Comments on pitch relate to Mode 5 'neutral' only):
1) The packing duration starts at the beginning of a motif.  Overlaps can be achieved by making motifs different lengths as well as setting the packing to be less than the duration of a motif.

2) Note how 'even' durations (e.g. packing for a triplet figure begins at 0.34 or 0.33) result in chordal effects

3) Packing longer than a motif will produce pauses, which will be 
exaggerated if multlo-hi is a faster tempo.  (NB: mult is a multiplier: mult > 1 slows the tempo because it makes the duration longer, mult < 1 increases the tempo because it shortens the duration).

4) If more than one input sound, the sound is chosen at random for each motif iteration, but plays all of the notes in that motif.  But what is playing which motif is obscured by the fact that the sounds keep changing.

5) Each motif is started on a pitch taken at random from the pitch range and, in Mode 5 ('neutral') then plays its pitches accurately as defined in the motif, but beginning on (transposed to) that start pitch.

6) The pitch range on command line vs. pitch range of motifs.  There are various ways to play with this:
  a) Pitchlo-hi on the command line is the same pitch:  all notifs 
     will begin on this pitch, but play their defined motif pitches 
     from that starting point
  b) If pitchlo-hi on the command line covers a range of pitches, 
     each motif will begin on one of these pitches chosen randomly, but then play its motif accurately from that starting point.
  c) As in ndfmotif4.txt, all motifs are on the same pitch, thus 
     producing repeated notes.  These can be repetitions all on the 
     same note (case 'a') or repetitions on various pitch starting points (case 'b').

7) Note that multilo-hi controls tempo: 1 is same as ndf), 2 is twice as 
     slow, and 0.5 is twice as fast -- it's a multiplier of duration
     
8) If a harmonic field or set is used (TEXTURE MOTIFSIN), pitchlo-hi on the command line needs to be set to the pitch range of the field or set to accommodate all the possible starting points defined by that field or set -- otherwise they will omitted.  The pitches of each motif are forced onto the pitches of the defined field or set, causing serendipitous pitch repetitions or warpings of the motif.

9) TEXTURE MOTIFS is more flexible than TEXTURE TIMED:  it has fully  defined motifs which can be used in various ways as described above, it has the 'packing' parameter which allows much more overlapping than the 'skiptime' parameter, and it has the multlo-hi tempo control.  TEXTURE POSTORNATE uses skiptime, but it has a nodal substructure mechanism ('line') that can be used to control overlaps, even to the point of creating canonic melodic lines.
