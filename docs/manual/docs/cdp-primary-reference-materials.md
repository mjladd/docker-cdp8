**Materials –** {#MATERIALS} Access these materials *via* the MAIN INDEX to the CDP Software: ..docs/index.html

The CDP software for sound design comprises a huge and possibly bewildering suite of programs. A variety of materials are available for your personal study and sonic explorations. It is very much in your interest to make use of a number of core documents that will clarify what it is all about and enable you to find the processes needed to realise what stirs in your sonic imagination. Do not look for 'black box' solutions. The real power of the CDP software lies in combining processes to sculpt sound in innovative ways and in ever finer detail.

- ***CDP Guide* –** {#CDPSYNOPSIS} I would first like to call to your attention a set of documents called simply *cdpguide.html*. Written by Robert Fraser, the author of *Soundshaper*, this set of documents provides a synopsis of the whole set of CDP programs for sound design, an 'eagle's view' from above, as it were. The purpose of each program Group is first described, and then each program in that group is listed along with a brief description and some insightful observations. Printable PDFs are provided. I have printed out my copy and it will be a primary resource when composing. This Guide has been incorporated into the CDP Documentation download and will be found \docs\guide.

- ***CDP Reference Documentation* –** {#HTMLDOCS} [../docs/index.html - MAIN INDEX tab] This provides the complete command line usage for a program, a section on understanding what it does, and a third section suggesting possible musical applications. Written over many years by Archer Endrich, it has recently been restructured and adapted for HTML-5 by Robert Fraser, who now maintains these documents. On an installed CDP system, the link to the Reference Documentation is (e.g.) `C:\cdpr7\docs\index.html`. The first part of this path may differ if you have set up the CDP software in another place or with a name other than 'cdpr7'.

  The *SoundLoom* reference manual is *Sndloom.htm* in \cdpr7\docs\html and the *Soundshaper* reference manual is *MANUAL.html* in \cdpr7\docs\Soundshaper.

- ***CDP Desk Reference* –** {#DESKREF} [..docs/DeskReference] This document lists all the CDP functions, their inputs and modes with a brief description of each. It is useful to peruse it in order to see what's available, find the name of a program, and check on inputs required. It is available in pdf format via the CHARTS tab in the Reference Documentation. It is highly recommended to have a printed copy to hand.

- ***CDP Files & Codes* –** {#FILESCODES} ['File Formats' link that comes up when you access a program group or other tabs *via* the MAIN INDEX] This important document explains and gives examples for all the different types of supplementary (text) file that can be used with the CDP programs. The file itself is ../docs/html/filestext.htm (a Desktop Shortcut is recommended.)

- ***Charts* –** {#CHARTS} [MAIN INDEX => CHARTS tab] The CHARTS tab links to several charts designed to provide information in a concise way. You can also find the files in .../docs/charts and pdf versions in .../docs/chards-pdf. I have laminated printouts of these charts. Among them are charts for:
  - **Equivalent Pitch Notations** (Note name - *Csound* Pitch - MIDI Pitch - Frequency in Hz) – quickly find a MIDI pitch you might need for a tuning or Texture file. [*Note Chart.pdf* or *Note Chart-alt.pdf* (without table lines)]
  - **Gain - dB Correlations** – helps with deciding on gain levels [*Gain-Db Chart.pdf*]
  - **TEXTURE Note Data File Chart** – shows what needs to go into the note data file ('ndf') for each TEXTURE program, and in doing so shows what each program does. [*TEXTURE NDF Chart.pdf*]
  - **Two Useful Reference Charts for TEXTURE** – gives written out examples of the various note data files and then reviews the components used by each program [*2 Texture Reference Charts.pdf*]
  - **Chart of Transposition Ratios** – shows the rations for two octaves up and down, number of semitones and which interval each creates. Ratios can be used instead of semitones. [*Transposition Ratios.pdf*]
  - **Transposition & Shifting Inputs and Outputs** – The REPITCH functions for combining transposition, envelope, and binary pitch data files are an advanced but very powerful part of the CDP software. The various files and how they are combined are summarised in this Chart, and their use is discussed in Tutorial Workshop 3: *Guide to Transposition & Frequency Shifting with CDP* [*REPITCH Inputs & Outputs Chart.pdf*]
  - **Abbreviations for Key CDP Functions** – Robert Fraser has compiled this Chart to help identify functions in filenames, such as 'avg' for BLUR AVERAGE. [*CDP Function Abbreviations.pdf*]

- ***A User's Guide to* Sound Loom *and CDP Sound Transformation Software* –** {#SLGUIDE} Written by Trevor Wishart, this is a comprehensive manual for the CDP System as approached *via* the *Sound Loom* GUI. Also accessed via the TUTORIALS tab, the link is `.../docs/SpecialHelp/twSoundLoomGuide.pdf`.

- **Technical Glossary –** {#TECHGLOSS} [MAIN INDEX => CHARTS tab] This list provides some basic information about a number of important technical terms used in electroacoustic music.

- **Musical Glossary –** {#MUSGLOSS} [MAIN INDEX => CHARTS tab] Terms and concepts that relate to composing music in the medium of sounds are described in this glossary, meant to infuse the technical with the creative.

- ***Demo 1: 6 worked examples* –** {#DEMOEXS1} MAIN INDEX => TUTORIALS tab *Dice Demo* link. These examples (with sounds) show how various sounds and sound textures are created by means of chained processes (meaning that the output of one process becomes the input to the next), mixing, and time-varying breakpoint files.

- ***Demo 2: Examples in 8 categories* –** {#DEMOEXS2} [MAIN INDEX => TUTORIALS tab *CDP Tour Examples* link] These provide detailed examples (with sounds) of processes belonging to 8 different categories, showing parameter settings and supplementary text files.

- ***Sound Design - The Expressive Power of Music, Voice, and Sound Effects in Cinema* –** {#SONNENSCHEIN} Written by David Sonnenschein and published by Michael Wiese Productions. 2001. This text is about sound design generally, not about the CDP Software. However, it is highly recommended. I bought my copy from the author at ICMC Glasgow 1990 and have worn it out! About sound design in films, and widely available, this is a great book for developing a deeper understanding of the musical use of sound. It illustrates the use of sound in great depth and how it can be used to support the narrative dimension of films. It is concerned with creative sound design rather than software systems.

- ***Composing Electronic Music - A New Aesthetic* –** {#ROADSELECTRONICMUSIC} by Curtis Roads (OUP, Oxford, 2015). This is a fantastic book by an electronic music composer with decades of experience as composer, author and teacher. It covers both technical and aesthetic issues and has many sounding music examples available online at: https://www.oup.com/us/composingelectronicmusic
