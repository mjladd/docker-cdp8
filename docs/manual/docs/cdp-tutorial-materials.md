- **_CDP Tutorial Workshop 1_** {#WKSHOP1} – One good way (among others) to get started with CDP is to listen through the 170 or so sound examples in *CDP Tutorial Workshop 1*. It is freely available on the [CDP Website](http://www.composersdesktop.com). It illustrates many of the possibilities of the CDP sound design software in 9 categories, with explanations on the various worksheets of how each sound was made. This can be a very helpful reference tool for getting the measure of the CDP software and when trying to find processes relevant to specific sonic requirements. The 'listening' sections often link to a selection of these sounds, usually joined up as one soundfile).

    Written by Archer Endrich when teaching at Wiltshire College Chippenham, this Workshop provides over 170 worked examples in 9 sound transformation categories, with full text and sound examples. It is downloadable from the CDP Website. There is also a playlist designed to play all the examples in sequence.

- **_CDP Tutorial Workshop 2_** {#WKSHOP2} – Written by Archer Endrich, this tutorial provides 21 worked examples which thoroughly explore the very powerful TEXTURE Set of programs. It includes a 5 x 4 table of links to the soundfile examples, read across to show the same type of constraint and mode at work in the various TEXTURE programs. Read downwards, it shows the different types of constraint at work in (mostly) the same program.

- **_CDP Tutorial Workshop 3_** {#WKSHOP3} – Guide to Transposition & Shifting with CDP Written by Archer Endrich, this tutorial unravels the amazing combinations of pitch and transposition data that can be done with the CDP REPITCH programs. A pitch trace (**.frq**) can be extracted and then turned into a transposition file (**.trn**). This can be done with two source files and the pitch trace and transposition files combined with each other in various ways.

- **_A Learning Manual for CDP_** {#ALM} – Written by Archer Endrich, it comprises 33 separate HTML files, each of which focus on specific areas of the CDP software. Grown out of personal experience using the software, it contains a number of tips and detailed discussion of some tricky areas. There are many musical sound examples and several practical worksheets. It can be downloaded from the CDP Website.

- **_12 Step Tutorial_** {#TUT12STEP} – Written by Archer Endrich in 2006, these 12 steps take the user from a general orientation (intro) to suggestions about project management (12) and cover getting and editing sounds (1), playback (2), transposition (3), time contours (4) analysis (5), filter banks (6), distortion (7), envelopes (8), transitions (9), mixing (10) and textures (11). It provides a reasonably concise but thorough overview of the CDP System and is peppered with screens from the *Sound Loom* and *Soundshaper* GUIs. [..docs/htmltuts/tut12step/tut12stf.htm – this is the 'frame' document in pre-HTML5.]

- **3 _GrainMill_ Tutorials** {#GRAINMILL} – Three tutorials for Richard Dobson's granular manipulation program, *GrainMill*, a graphic version of MODIFY BRASSAGE. *GrainMill* is PC only (unless running in Parallels), but these tutorials provide a variety of examples of granulation that can be realised by other means. Note that Richard has also written a companion program, *BRKEDIT* which provides graphic facilities for creating, viewing and comparing breakpoint files.
    - **'A Big One'** – a time-varying granulation of a phrase (spoken by Peter Karkut), showing all breakpoint files. (This is the first example in 'DiceDemo'.) [..docs/htmltuts/grntuts/ae/abigone.htm]
    - **A _GrainMill_ Tutorial** – by Philippos Theocharidis. Philippos Theorchardis carefully explains how to achieve five different types of effect. [..docs/htmltuts/grntuts/philippos/grntutor.htm]
    - **_GrainMill_ Examples** – 16 examples with a playlist prepared by *GrainMill's* author, Richard Dobson [..docs/htmltuts/grntuts/rwd/RDplayex.htm]

- **DRUNK Tutorial** {#DRUNK} – by Archer Endrich, there are 6 worked examples involving intricate breakpoint files. [..docs/htmltuts/drunk/drunktut.htm]

- **Landy on Electroacoustic Music** {#LANDY} – *Sound Transformations in Electroacoustic Music* (1991) is a comprehensive and insightful essay covering Background, Aesthetics, Musical Context, and Categories of Sound Transformation. [..docs/html/landyeam.htm]

- **Dobson on PVOC** {#DOBSON} – *The Operation of the Phase Vocoder* (1993) covers 8 topics about phase vocoding providing a much deeper understanding of the technical aspects of FFT processing. [..docs/html/Operpvoc.htm]

- **Hunt: 3 _Csound_ Tutorials** {#HUNT} – Many CDP users regard *Csound* as an important complement to the CDP Software. It is the world's premiere sound synthesis program. It can also handle soundfile input, so CDP-produced files can be used, for example by *Csound* score files. Andy Hunt's Tutorials provide a good starting point.
    - Part 1 - Origins of *Csound*: Historical & Musical Setting
    - Part 2 - Simple Guide to *Csound* Operation
    - Part 3 - Signal Processing
