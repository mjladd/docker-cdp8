## Overview

## Installation

Unpack anywhere, e.g. to the top level of C or to a directory of your choice. You will then have:

### Directory Structure

```
\CDPWorkshop3
  \T-SworkshopMAC          main folder with the Workshop materials
                           to RUN on MAC click on Trnsshft-MAC.htm
  *.brk                    breakpoint files used by the Workshop
  *.frq                    frequency trace files used by the Workshop
  *.trn                    transposition files used by the Workshop
  *.txt                    text files used by the Workshop
  *.wav                    soundfiles used by the workshop
    /Bat-TSworkshopMAC     backup copies of original .sh batch files

  \T-SworkshopPC           main folder with the Workshop materials
                           to RUN on PC click on Trnsshft-PC.htm
    \Bat-TSworkshopPC      backup copies of original .bat batch files
  *.brk                    breakpoint files used by the Workshop
  *.frq                    frequency trace files used by the Workshop
  *.trn                    transposition files used by the Workshop
  *.txt                    text files used by the Workshop
  *.wav                    soundfiles used by the workshop
```

### Running the Workshop

- **Mac:** Click on `Trnsshft-MAC.htm`
- **PC:** Click on `Trnsshft-PC.htm`

## Adapting the Workshop

The batch files in the main folder can be adapted if you wish to explore the operation of the programs further, e.g., simply by changing the input soundfile that is processed.

### Important Notes

1. If you wish to do this, you may want to make a copy of the Workshop in a new folder so that the original remains unchanged.

2. If you do want to adapt a batch file, **RUN THE DELETION FILE FOR THAT BATCH FILE FIRST** to clear the current inputs -- and before any further runs.

3. The batch files in `Bat-TWworkshopMAC` and `Bat-TSworkshopPC` are copies of the original batch files. They can therefore be used to restore the original settings and soundfile outputs.
