# Listening2-Surfaces

*by Dr Archer Endrich*

## Listening2-Surfaces {#INTRODUCTION}

*listen for the way the [source sound](../sounds/clip2-1-flexatone.wav) is roughened, extended and granulated*

This group of sounds comes from Worksheet 3 of *CDP Tutorial Workshop 1*. The source sound in the Workshop is track 48, followed by tracks 49 to 60 which illustrate wavecyle distortion, looping scrambling and brassage. The whole series is presented here as a single soundfile: [clip2-all.wav](../sounds/clip2-all.wav), but each sound can also be accessed individually.

1. Source sound - [clip2-1-flexatone.wav](../sounds/clip2-1-flexatone.wav)

2. DISTORT REPEAT - [clip2-2-flexdr2-2.wav](../sounds/clip2-2-flexdr2-2.wav): Repeat 2 groups, with 2 wavecycles in each group

3. DISTORT REPEAT - [clip2-3-flexdr4-5.wav](../sounds/clip2-3-flexdr4-5.wav): Repeat 4 groups, with 5 wavecycles in each group

4. EXTEND LOOP - [clip2-4-flexloops1_3.wav](../sounds/clip2-4-flexloops1_3.wav): Loop with 1/3 overlap: *length* 300ms, *step* 100ms

5. EXTEND LOOP - [clip2-5-flexloops4_5.wav](../sounds/clip2-5-flexloops4_5.wav): Loop with 4/5 overlap: *length* 100ms, *step* 20ms

6. EXTEND SCRAMBLE - [clip2-6-flexscramble1a.wav](../sounds/clip2-6-flexscramble1a.wav): Chunks are between 0.1 and 0.3 sec in length

7. EXTEND SCRAMBLE - [clip2-7-flexscramble1b.wav](../sounds/clip2-7-flexscramble1b.wav): Chunks are between 0.06 and 0.2 sec in length

8. EXTEND SCRAMBLE - [clip2-8-flexscramble2.wav](../sounds/clip2-8-flexscramble2.wav): Mode 2 rearranges the segments, and *scatter* is 3

9. MODIFY BRASSAGE - [clip2-9-flexgrnstr.wav](../sounds/clip2-9-flexgrnstr.wav): Mode 2 with x4 *timestretch* (1 ÷ 0.25 = 4)

10. MODIFY BRASSAGE - [clip2-10-flexgrnstrtv.wav](../sounds/clip2-10-flexgrnstrtv.wav): Mode 2 with time-varying *timestretch*

11. MODIFY BRASSAGE - [clip2-11-flextvgrains](../sounds/clip2-11-flextvgrains.wav): Mode 4, *grainsize* varies between 25 and 200 ms

12. MODIFY BRASSAGE - [clip2-12-flexgrainy](../sounds/clip2-12-flexgrainy.wav): Mode 5, granulate the sound with tiny gaps (*density* is 0.75)

13. MODIFY BRASSAGE - [clip2-13-flexbrassage.wav](../sounds/clip2-13-flexbrassage.wav): Mode 7, multi-parameter time-varying
