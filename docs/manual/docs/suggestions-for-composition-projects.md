# Suggestions for Composition Projects

*by Dr Archer Endrich*

*Kickstarting the composition process*

When preparing to compose with sounds, it may be a good idea to focus on a very specific area for a while. One way to do this would be to ring the changes on only one program. It can also be useful to enter parameter values at the extremes and then work inwards. This can give you a feel for the processing scope of that program, and values beyond legal limits generate error messages that reveal/confirm where those limits are.

It is hard to predict what a given source sound is going to respond to process, which is part of the enjoyment of working with sound. There is no substitute for exploring, trying things out with a sense of play and a spirit of enquiry. Watch for the unexpected great result and keep it! (and how it was done), for it may not happen again. Think hard about why that parameter value may have produced that result, which will help get 'inside' the workings of the software.

Larger compositions with varied components can come later. Here are a few suggestions:

- Apply the same process to various input sounds
- Work through one process group with one or more input sounds, such as filtering, segmentation, distortion
- Tell a story in sound, i.e., work to a narrative
- Concentrate on the various ways to mingle sounds: transitions, crossovers
- Explore the processing of spoken words
- Build strong tones, and with them create melodies and harmonic textures
- Make rhythms and rhythmic textures with drum and metal sounds, such as with rhythmic templates and defined motifs
- Create 'visual' shapes with time-varying pitch breakpoint files
- Realise soundscapes with natural, lightly processed sounds
- Consider the symbolic ambience of sounds and construct a narrative with them
- Create multi-event textures using one or several sound inputs at once, along with optional use of time-varying *packing*, *pitch*, *amplitude*, *tempo*, and *pan-position*
